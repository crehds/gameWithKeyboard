# Game With Keyboard

A keyboard-based memory game in the style of Simon.

## Available Scripts

In the project directory, you can run:

### `npm run dev`

Starts the Vite dev server.

### `npm run build`

Type-checks the project, then builds the app for production into the `dist` folder. A type error fails the build, so it also blocks deploys.

### `npm run preview`

Serves the production build locally for a final check.

### `npm test`

Runs the test suite once with Vitest.

### `npm run test:watch`

Runs the test suite in watch mode.

### `npm run lint`

Lints the `src` folder with ESLint.

### `npm run typecheck`

Type-checks the project with `tsc --noEmit`.
